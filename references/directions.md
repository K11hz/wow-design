# Visual Directions

Choose one direction and adhere to it consistently across the entire project.

## 1. Tech Dark (Linear / Vercel / Raycast)
- Near-black background with a cold deep-blue undertone, 1px translucent borders, subtle accent glow behind focal elements, subtle dot or grid background texture.
- Typography: Geist / Inter + monospace for technical details (Geist Mono, JetBrains Mono).
- Signature Feature: Illuminated card border gradients, cursor-following spotlight, animated beam connectors.
- Motion: Snappy, precise, understated.

## 2. Editorial (Magazine / Luxury Brand)
- Warm off-white background, massive high-contrast serif headlines, generous whitespace, thin dividing rules.
- Typography: Fraunces / Instrument Serif + Inter.
- Signature Feature: Monumental typography, asymmetric editorial grid, photography with subtle caption notes.
- Motion: Slow, graceful reveals, image parallax.

## 3. Bold Brutal (Neo-Brutalism / Expressive)
- Vibrant flat colors, thick dark borders, high-contrast hard drop shadows (`shadow-[6px_6px_0_#000]`), bold sans-serif display.
- Typography: Unbounded / Clash Display + Manrope.
- Signature Feature: Sticker-like tags, continuous ticker/marquee, intentionally irregular masonry grid.
- Motion: Bouncy, tactile spring physics.

## 4. Glass & Aurora (Soft Modern Futurism)
- Dark or light canvas with large, blurred mesh-gradient spheres, frosted glass cards (`backdrop-blur`, translucency, top-edge specular highlight).
- Typography: Space Grotesk / Onest + Inter.
- Signature Feature: Slow-moving organic gradient mesh, interactive 3D model (Three.js / React Three Fiber / Spline).
- Motion: Fluid, floating, ambient breathing animations.

## 5. Minimal Swiss (Apple-Inspired Craft)
- Ample pure whitespace, single font family across multiple carefully tuned weights, rigorous grid alignment, oversized product imagery.
- Typography: Inter / Geist (single typeface hierarchy).
- Signature Feature: Scroll-driven sticky scenes where the product rotates or unpacks dynamically.
- Motion: Cinematic, tightly coupled to user scroll position.

## 6. High Octane / Cyber (Gaming / Simulators)
- Dark technical base, electric high-saturation accents (crimson, acid yellow, neon cyan), angled clip paths (`clip-path`), HUD-style overlays, monospace metric counters.
- Typography: Rajdhani / Chakra Petch / Unbounded + Inter.
- Signature Feature: Cockpit HUD elements, animated speedometer/metric tickers, subtle scanlines, ambient video background.
- Motion: Sharp, rapid, high-momentum transitions with simulated motion blur.
