# Визуальные направления

Выбери одно и придерживайся его на всём сайте.

## 1. Tech Dark (Linear / Vercel / Raycast)
- Фон почти чёрный с синим подтоном, тонкие 1px-границы, свечение акцента за элементами, сетка/точки на фоне.
- Шрифты: Geist / Inter + моно для деталей (Geist Mono, JetBrains Mono).
- Фишка: светящаяся линия-граница карточек, прожектор за курсором, анимированный beam.
- Движение: сдержанное, точное, быстрое.

## 2. Editorial (журнал / премиум-бренд)
- Светлый тёплый фон (off-white), крупный серифный заголовок, много воздуха, тонкие линейки.
- Шрифты: Fraunces / Instrument Serif + Inter.
- Фишка: огромная типографика, асимметричная сетка, фото с подписями как в журнале.
- Движение: медленное, плавное появление, параллакс изображений.

## 3. Bold Brutal (дерзкий, молодёжный)
- Яркие плоские цвета, толстые чёрные обводки, жёсткие тени со смещением (`shadow-[6px_6px_0_#000]`), крупный гротеск.
- Шрифты: Unbounded / Clash Display + Manrope.
- Фишка: наклеечные элементы, бегущая строка (marquee), неровная сетка.
- Движение: пружинистое, игривое (spring).

## 4. Glass & Aurora (мягкий футуризм)
- Тёмный или светлый фон с большими размытыми градиент-пятнами, стеклянные панели (`backdrop-blur`, полупрозрачность, блик сверху).
- Шрифты: Space Grotesk / Onest + Inter.
- Фишка: медленно движущийся градиент-меш, 3D-объект (Three.js / React Three Fiber / Spline).
- Движение: плавающее, дышащее.

## 5. Minimal Swiss (Apple-стиль)
- Много белого, одна гарнитура разными весами, строгая сетка, огромные продуктовые изображения.
- Шрифты: Inter / Geist (один шрифт).
- Фишка: scroll-driven сцены — продукт вращается/собирается при прокрутке, sticky-секции.
- Движение: кинематографичное, привязано к скроллу.

## 6. Gaming / Racing (для тематики игр и симуляторов)
- Тёмный фон, неоновый или "гоночный" акцент (красный, оранжевый, кислотный), скосы и диагонали (`clip-path`), HUD-элементы, моноширинные цифры.
- Шрифты: Rajdhani / Chakra Petch / Unbounded + Inter (проверь кириллицу).
- Фишка: HUD-интерфейс, спидометр-счётчики, glitch/scanline-эффекты, видео-фон.
- Движение: быстрое, резкое, с motion blur.
